# Journal of Electrocardiology submission package — withdrawn

**Withdrawn before submission, June 2026. Retained for provenance. Do not use.**

This is the complete submission package prepared for the *Journal of
Electrocardiology*: manuscript (DOCX and PDF), cover letter, highlights, and
submission figures.

It was withdrawn before submission following the June 2026 parameter audit.
Every figure and every quantitative statement in the text is built on the hERG
parameter table that was invalidated by that audit — see
`archive/params_invalidated_202606/README.md` for the three error modes found.

Nothing here should be reused as-is. The manuscript will need to be rewritten
against the rebuilt parameter table in `params/`, and all figures regenerated.

Note: the three PDFs in this directory are excluded from git by the `*.pdf` rule
in `.gitignore` and exist only on local disk.
